# football-analysis
Learning Python by analyzing football stats

## What I learned
- Day 1: variables and print, Divisions and round, Comments with #
- Day 2: if/else and comparisons (>, >=), lists, for loops and enumerate
- Day 3: Used a loop to go through two lists together and a condition inside the loop
- Day 4: Used a table to store players, goals and matches, added a new column for goals per match, and filtered players with more than 1.5 goals per match
